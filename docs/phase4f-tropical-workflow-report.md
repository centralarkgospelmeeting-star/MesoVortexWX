# Phase 4F — Tropical Workflow Report

## Dedicated control
"Open Tropical Mode" in the menu switches to Satellite, enables the verified
hurricane layer, and opens the Tropics panel. It does not add a fake mode product.

## Verified sources
- **NHC / CPHC**: `/api/tropical/cyclones` (CurrentStorms.json + NHC MapServer
  forecast points, track, cone, wind radii). Authoritative for Atlantic and
  Eastern/Central Pacific systems.
- **JTWC**: new `/api/tropical/jtwc` proxy reads the public JTWC RSS feed
  (`metoc.navy.mil/jtwc/rss/jtwc.rss`). Live probe returned HTTP 200 with real
  bulletin items. The Tropics panel lists title, publication time, and source
  link; when the feed is unavailable it shows `DATA UNAVAILABLE`.

## Displayed
Active tropical systems, forecast positions/cones where the NHC layer provides
them, JTWC products, and the current satellite view. "No placeholder storms" is
stated in the UI. No storm, track, or forecast point is generated by the app.

## Limitation
JTWC RSS carries bulletins, not a verified GeoJSON position/cone feed; the app
does not convert bulletin text into plotted forecast positions.
